# Mockups: site navigation (proposal, awaiting approval)

Public site navigation, modeled on the grouped menus of large Brazilian real-estate portals and adapted to Casvitta's coverage (São Paulo, neighborhoods that pass the publication threshold).

| File | What it shows |
|---|---|
| `header-desktop` | Header with five dropdown menus (Comprar, Alugar, Vender, Ferramentas, Para profissionais), one state per open menu |
| `menu-mobile` | The same tree as an accordion in the mobile menu, "Comprar" expanded |
| `home-blocks` | Link blocks on the home page, below the search and the simulator: neighborhoods (Comprar/Alugar tabs), popular searches, tools |
| `site-map` | `/mapa-do-site`: every page by topic, linked from the footer |

Rules for the build:
- Neighborhood lists come from the market API (`indexable` neighborhoods), never hard-coded. No link points to an empty or noindex page.
- Menus open on click and keyboard (Radix NavigationMenu), not on hover alone; Esc closes; one menu open at a time.
- Touch targets are 44 px or more in the mobile menu.
- Listing links open the search with demo listings until real listings exist; those listings keep the "Demonstrativo" badge.
- "Ferramentas" replaced "Preços" at the user's request (21/11/2026).

Generated by a script with the real neighborhood names in production on 21/11/2026; the HTML uses the same inline-style format as the other mockups.
